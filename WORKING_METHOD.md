## Source-first experiment

1. Inspect the existing AIGovern-Cyber runtime read-only and select the PD mechanism, operational contract, projection and supporting primitives.
2. Record original hashes, inclusive ranges, transformations and output hashes. Preserve attribution and separate copied source, modified extracts and new Store code.
3. Assemble a standalone dependency closure; exclude private histories, operational WALs, frozen evidence and unrelated source.
4. State the boundary before interpreting results: continuity advances operational state without native knowledge verdicts or science-query evaluation.
5. Compare uninterrupted execution with one OS process per turn using exact checkpoint bytes. Test retries, stale heads, changed inputs, scope isolation, corruption, incomplete tails and ownership.
6. Retain accepted valid rollback as an adverse finding, not a rollback-prevention claim.
7. Record commands, toolchains, outputs and artifact hashes. Distinguish the tested package from later release metadata.
8. Invite reproducible counterexamples and retain original findings when later revisions change behavior.
